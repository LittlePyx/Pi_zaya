# π-zaya Take11 全新重录脚本

目标：废弃 Take10 的大框线、低码率、导演指令旁白和长静止停留，重新录制一版更清晰、更连贯的长版广告母版。

统一素材源：`docs/ad_assets/pi_zaya_20260609/take11_blocks.json`

## 制作原则

- 画幅：`1280x800`。
- 录制源：不使用 Playwright 低码率 `recordVideo` 作为母版，改用高质量帧序列再由 ffmpeg 高码率合成。
- 视觉引导：保留鼠标和短点击光圈，禁止蓝/绿/橙大框线。
- 字幕：从旁白脚本生成，不能含导演指令；Reader、导出、输入区镜头优先使用顶部字幕，避免挡住底部控件。
- 节奏：单个静态画面不超过 `8s`；每段都有点击、滚动、展开、计数变化或范围切换。
- 品牌：全部使用希腊字符 `π-zaya`。

## 长版结构

| 段落 | 时长 | 画面目标 |
|---|---:|---|
| 01 开场 | 18s | 品牌定位，说明不是单篇 PDF 聊天 |
| 02 Library | 60s | 文献库、搜索、分类、标签、可问答状态 |
| 03 质量中心 | 45s | 转换质量、可修复入口、来源可靠性 |
| 04 Reader 顶部 | 35s | 论文第一页结构保持 |
| 04 Reader 公式 | 45s | 展示公式、编号、上下文 |
| 04 Reader 表格 | 45s | 展示表格、数字结构 |
| 04 Reader 图片 | 45s | 展示图片、图注、正文连续性 |
| 05 全库提问 | 50s | 输入真实研究问题，选择全库范围 |
| 06 结构化回答 | 70s | 展示分层回答和来源标记 |
| 07 引用卡 | 60s | DOI、期刊、指标、打开、入篮 |
| 08 原文核查 | 80s | 展开单页 Reader，定位证据和文内引用 |
| 09 文献篮 | 55s | 多篇入篮、计数变化、勾选限定范围 |
| 10 导出引用 | 55s | BibTeX/RIS/Markdown/GB/T/CSV |
| 11 写作提纲 | 40s | 用文献篮作为上下文提出 related work 问题 |
| 12 收束 | 25s | 品牌收尾，可问、可查、可引用 |

总时长约 `12:08`。

## 验收标准

- 最终视频码率不低于 `8 Mbps`，推荐 `CRF 15` 高质量导出。
- 任意抽帧中，右侧栏不被裁切，鼠标点击位置不偏。
- 字幕不遮挡 Reader 公式、图像、文献篮计数、导出按钮、输入框。
- 视频里不出现“广告里”“画面中要”“应该停留”“镜头”等导演指令。
- 文献篮部分必须看到多篇条目和勾选动作。
- Reader 转换质量段必须展示公式、图片、参考文献，而不是只讲摘要。
- 问答段必须展示全库范围和真实研究问题。
