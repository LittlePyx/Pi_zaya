## 实际修改

- 本地语义检索从用户选择的完整来源范围取得路径，在范围内评分后取 top K；不再从 BM25 命中反推范围，也不先截取全库前 40 再过滤。覆盖 BM25 零命中和范围内第 81 名的反例。融合后再应用文献篮摘录限制。
- BM25 保持默认及全库路径。本地语义组件需明确启用和验证；当前候选未配置组件发行清单时自动保留 BM25。历史实验协议、语料、结果及其源码指纹保持原样；新代码不改写旧指标。
- 回答核验增加中英文明确相反动作的保守约束，包括保留/丢弃、训练/冻结、提高/降低。没有发现冲突不等于证明支持；仍不是完整 entailment。既有数值、单位、来源身份及质量排除继续生效。
- ADMM 来源追问的上游引用绑定到明确的来源结论。快速回答和普通回答共用此逻辑，保持原 sid/参考文献编号。成像公式问题不再因“解释压缩图像”误入图表讲解；公式中的掩模乘法、求和、加性噪声可与中文解释对齐。FDM 卡片保留编码、复用、解调的完整原文链。
- 模型已配置与连接已验证分开；成功/失败测试与配置指纹绑定并持久保存。持久检查不存 API Key 或模型回复。配置变化后旧结果失效；首次引导不会偷偷调用模型验证。
- 可用文献计数核对索引状态和实际分块文件。首次引导完成还需在回答证据关联的同一来源成功定位；打开论文、章节或失败定位不计为完成。
- 单服务器/Windows 模式为 `/library`、`/notes`、`/reader/session/:id` 提供 React 入口，修复阅读器新窗口 404；未知 API、资源和路径仍返回 404。
- README 区分公开 beta.13 与未发布 beta.14；内部证据工作区保持隐藏。用户功能始终服务于文献阅读和来源明确的证据整理。
