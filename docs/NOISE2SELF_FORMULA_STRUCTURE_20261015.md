## 实际复现与修复边界

原 PDF 第2页的命题2以期望表达式的右方括号结束；下方的 for each subset 是正文量词。
`n2s-r24-baseline/` 保存实际转换的抽取块、渲染输入、页渲染、文档后处理及源码散列。
可复现公式尾部多余的 `\inJ.`、单元素示例中的孤立等号、普通 J 和分组集合的书法体区别丢失。
原 PDF SHA256 为 `83c895ff86232c604ba09c88452f18db080f2d36acc1ffc113c8487cd0ab6fff`。

- 原公式裁取只要求 span 与公式区域相交。下一行高字框的成员关系符号仅约1像素相交，
  仍被收进公式。现在要求 span 的大部分面积在区域内，量词正文不再进入等式。
- 同一 PDF 原始块中，等号与左侧正文具有相同基线，却被 MuPDF 分成两条逻辑行。
  现在只合并同块、同基线、水平相邻的片段；不同基线和远端列的等号保留。
- 原提取只拼接 span 文本，丢弃字体。现在依据 PDF 的已知 CMSY 字体保留书法体字母，
  普通 CMMI、Times 及未知字体的 J 保持普通 J；不根据论文名或符号语义猜测字体。
  使用显式 TeX 标记，避免 Unicode NFKC 再把数学字体折叠为普通字符。
- 单基线公式依据真实 glyph origin、字号和相邻位置恢复脚本，保留函数的星号、分组下标，
  以及 `x_{J^{c}}` 的嵌套补集。多行、基线上的小字和远端脚本不套用这条路径，沿原回退。
- 短量词及优化目标说明保持正文；带行内字体标记的短正文也不误分为独立显示公式。
  命题标签开始独立段落，使指定命题的直接召回同时携带同页正文、等式和量词。

修改集中于 `pdf_math_geometry.py` 及原提取/渲染接入，不增长受保护大文件。
从大型渲染模块搬出的旧几何回退保留，新增模块承接 PDF 字体与基线解码。

## 负例与审计

错误字体、删除补集、系数改为2和追加成员关系尾部，均不能取得来源完全匹配的公式保护。
新增负例进一步暴露：同一行 `$$...$$` 的改式可能被普通逐句校验跳过，原失败4项保留。
严格修复路径现在对同一个来源定义的等式左端执行冲突否决，审计记录具体被拒公式。
检测冲突时忽略左端字体仅用于发现冲突，不授予支持；短的完全相同等式及无关表达式保留。
这是一条有限的关系否决规则，不是通用代数或蕴含证明器；没有降低支撑门槛。

新负例另覆盖未知字体、另一列文字、相邻量词、合法成员关系、多行公式、基线上小字、
不同命题编号和无匹配公式的另一来源。已有错误页码、块、来源及禁止引用号保护仍保留。
