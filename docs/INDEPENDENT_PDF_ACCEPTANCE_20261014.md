## 根据真实失败落实的修复

- 数学区间被当成引用清除：统一保护 Markdown 数学、代码和明确的数值区间；
  offset 重写、结构校验、文内引用提升与最终清理共享该边界。
  无效普通 `[0]`、`[0,1]`、越界 `[99]` 仍保持原有严格规则。
- 仅文献库仍追加模型知识：把会话 `external_supplement_mode` 传到最终补充入口，
  只有明确选择 `model` 才允许；`disabled` 和 `web` 都不能隐式授权模型背景。
  原来的模型补充测试也改为显式授权，原有内容断言保持不变。
- DnCNN 完整 41 条参考文献被误报截断：排除 `sigma in [0,55]` 这类数值区间。
- Noise2Self 正文公式尾部被误判为编号章节：仍要求同页原 PDF 字号证明，允许完整
  源文本以候选标题结尾；不放宽质量门禁。诊断规则版本从 15 升到 16，旧缓存重新扫描。
- 多段组合摘录缺页码：只在实际同来源 passage 文本和页码均匹配时绑定定位元数据；
  不从模型输出猜页码，不全局缩窄生成上下文。不同来源或错误页码的负向测试拒绝绑定。
  后续比较题只留下了一条本地摘录，**尚未在真实输出中验证两篇本地引用都定位正确**。
- Windows spawn 及流式 deadline：转换器公共导出改为惰性加载；读取排队首片段后再次
  检查共享首字节 deadline。没有延长原 8 秒进程启动断言或模型超时。
- 首次使用：构建语义索引时显示已完成/总数量，安装压缩包时继续显示安装进度。
- 真实增量任务发现取消竞争：已接受的取消/移除状态不能被后到的 worker 进度或
  ready 更新覆盖；完成/异常分支优先处理用户操作。进入索引阶段时清空安装字节进度，
  避免把压缩包字节数显示为索引数量。原先失败日志与红/绿测试都保留。
- 浏览器并发测试：关闭两个窗口前等待 journal 和转发请求结束，保留真实 SQLite
  竞争、409、丢响应重放与最终 revision 断言；不吞掉在途请求错误。

修复后针对原题集中 3 个失败问题复测（r5）：BM25 自动合同 2/3，混合 3/3；
阅读器 2/3 与 3/3，原 PDF 检查 5/6。DnCNN `[0,55]` 两模式都完整保留，
并在 PDF 第 6 页找到原句。BM25 跨文献比较仍无本地摘录；混合比较仅有 N2V 本地摘录，
另篇来源覆盖的自动判定不能证明第二篇也有直接本地引用。
这 3 题是修复诊断回归，不是新的独立样本，也不替换原 24 题的 14/24、15/24。
中间 r2–r4 的失败输出也保留；r2 曾因测试中发现错误的参数传递位置而全部失败，后已修正。

## 原文与回答的代理审阅

这轮对回答及相关原文做了代理定性审阅，没有人工审核或完整逐 claim 标注，
不计算人工准确率。物理可定位与语义支持应分别判断。主要残余问题是：

| 问题族 | 已见残余问题 |
|---|---|
| DnCNN 输出/训练 | 结论大体正确，但首条摘录有时只给网络结构或 TNRD 扩展，不能直接支持残差相减、BN 联合收益 |
| DnCNN 感受野 | 两模式遗漏论文明确给出的随深度变化公式 |
| N2N 理论 | 有限样本方差关系未召回；均值/中位数结论正确时仍可能引用间接说明；无偏条件表达不够精确 |
| N2N 应用 | 把相关工作当作本文应用，或遗漏 MRI；不能仅靠出现 Monte Carlo 等词判断完整正确 |
| N2V 数据/假设/模糊 | 部分答案缺“信号相关”条件；摘要噪声配对要求表述混乱；首轮有答案与摘录明确排除 blur 的表述矛盾 |
| N2S 命题 1 | 未召回完整等式和无偏条件，缺失答案仍可能因包含条件名称通过词组检查 |
| N2S 经典算法 | 回答转向 NLM/BM3D 实验对比，漏掉中值滤波器校准示例 |
| 跨文献比较 | 混合输出曾使用“唯一可行方案”的过强结论；有的段落引用另一篇的摘要或间接介绍，缺直接支持 |

下一轮应优先定位这些缺失的理论段落、公式及条件，并补直接支撑的引用和否定反例。
本轮不据一题差异新增 cross-encoder，不开放全库 dense。
