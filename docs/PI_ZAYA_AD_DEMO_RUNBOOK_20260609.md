## 2. 真实端到端提问

主问题，全库范围：

```text
单光子成像为什么需要专门建模噪声？有哪些代表性做法？
```

追问，进入单篇阅读指导后切换到“本文”范围：

```text
这篇论文为什么和刚才的问题相关？请用 3 点说明，并给出对应的原文依据。
```

备选长视频追问：

```text
把这篇论文的贡献、方法和局限，用面向 related work 写作的语言总结。
```

```text
哪些文献可以支持 SPAD / single-photon imaging 里的噪声模型背景？请给出 DOI 和用途。
```

## 3. 已跑通的端到端流程

1. 打开 React 应用：`http://127.0.0.1:5173/`
2. 在左侧栏展示 `π-zaya Demo` 项目和演示会话。
3. 在“全库检索：单光子成像的噪声建模”中提交主问题。
4. 等待检索与回答生成，展示答案和 `可能相关的参考文献`。
5. 展开 `参考定位`，展示页码、DOI、IF/JCR、Locate/PDF/Quote/Read 按钮。
6. 点击第一张文献卡的 `阅读`，进入单篇阅读指导。
7. 在阅读指导页切换到 `本文`，提交追问。
8. 点击答案里的 `原文`，打开右侧 Reader，展示高亮原文证据。
9. 打开独立 Reader 页面，点击文内 `[R1]` 引用。
10. 展示参考文献卡并点击 `加入研究摘录篮`。
11. 回到聊天页，展示项目级 `研究摘录篮` 已收藏 4 条。
12. 点击第一条摘录篮文献，展开详情，展示摘要/摘录、质量状态、来源路径和 DOI 外链。
13. 再点击同一条文献，收拢详情。
14. 展开第二条文献，展示另一条 DOI、来源位置和用途标签。
15. 勾选 2 条文献，打开 `导出引用`。
16. 切换 `选中 / 可见 / 全部` 导出范围，展示 BibTeX / RIS / Markdown / CSV / GB/T。
17. 打开 `文献管理`，展示 21 篇文献、转换状态、质量分与可问答状态。

## 5.1 研究摘录篮必拍细节

项目级摘录篮已经预置 4 条文献：

| 文献 | DOI | 镜头用途 |
|---|---|---|
| `Single-photon avalanche diode imagers in biophotonics: review and outlook` | `10.1038/s41377-019-0191-5` | SPAD 背景综述 |
| `First-Photon Imaging` | `10.1126/science.1246775` | 稀疏光子计数和噪声建模动机 |
| `Wide-field, high-resolution Fourier ptychographic microscopy` | `10.1038/nphoton.2013.187` | Reader 文内引用展开 |
| `Characterization-based modeling of retriggering and afterpulsing for passively quenched CMOS SPADs` | `10.1109/JSEN.2019.2903937` | SPAD 后脉冲/噪声模型 |

拍摄动作顺序：

1. 打开 `研究摘录篮`，先停在 4 条列表视图。
2. 点击第一条文献卡主体，展开详情。
3. 鼠标停在 DOI 链接上，说明它是可点击外链。
4. 展示摘要/摘录、来源路径、质量或匹配状态。
5. 再点击第一条文献卡主体，收拢详情。
6. 展开第二条文献，展示另一条 DOI 和标签。
7. 勾选两条文献，展示 `已选中` 批量状态。
8. 点击 `导出引用`，切换 `选中 / 可见 / 全部`。
9. 展示 `下载 BibTeX`、`RIS`、`Markdown`、`复制 GB/T`、`CSV 数据表`。

长视频录屏建议：

- 画幅：16:9，优先 1920x1080 或 2560x1440。
- 鼠标移动要慢，点击后停 1-2 秒。
- 答案生成阶段不要剪太快，保留“检索中/生成中”的可信感。
- 文献卡、Reader 高亮、导出面板每个至少停 4 秒，方便后期加字幕。

## 7. 拍摄注意事项

- 产品入口只使用 React + FastAPI：前端 `5173`，后端 `8000`。
- 不使用旧 Streamlit 入口、`app.py`、`streamlit run` 或 `8501`。
- 当前录屏主线使用真实页面操作完成；独立 Reader 可直接打开已生成的 reader session URL 来补拍。
- 如需重新生成答案，优先使用同两条主问题，保证广告和文档叙事一致。
- 画面中如出现旧测试会话，可裁切左侧栏顶部或只展开 `π-zaya Demo` 项目。
