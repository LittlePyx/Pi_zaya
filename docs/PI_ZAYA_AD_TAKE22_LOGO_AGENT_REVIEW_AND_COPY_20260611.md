## 专业审查

### 优点

- 开场终于有品牌记忆点，logo 动效比直接进软件页面更像广告。
- 蒙太奇覆盖的功能面更完整，观众能在前几秒知道这是“从 PDF 到引用/写作”的工作流。
- 新提问和 agent HUD 让产品定位更清楚：它不是搜索框，也不是普通聊天，而是在文献库上执行研究任务。
- Reader 图片段的文案比 take20 更具体，能解释为什么保留图像、图注和上下文会影响回答质量。
- 文献篮段已经停在上下文条，能说明“用于下一轮”不是收藏动作，而是下一轮回答的输入。

### 仍需注意

- v4 是混合声线兜底版：Edge TTS 网络超时，第 7 段和结尾段用 Windows 本地中文语音补齐。可发布前建议网络恢复后重生成这两段，以统一声线。
- Library 和 Reader 顶部段仍略快。如果要做更高级的品牌片，可以再加 8-12 秒，让质量中心和 Reader 各多停一拍。
- DOI 官页在成片里能看到 Download PDF，但网页文字较小；如果做 60 秒短版，建议只保留 DOI 按钮和来源卡片，不展开太多页面信息。

## 发布正文

给 π-zaya 一批 PDF，它会先整理文献库和转换质量，再在 Reader 里保留原文、图片、图注和解释。

提问时，它像 research agent 一样拆任务、检索文献、读取证据，生成带引用的回答。来源编号能打开 DOI 官页，文献篮还能作为下一轮写作上下文。

这条视频用 single-photon imaging 做示例，但领域由你的 PDF 库决定。

## 短文案版本

PDF 不应该只被“读完”。  
π-zaya 把文献库变成可问、可查、可引用的研究 agent：能回答、能回原文、能打开 DOI，也能把选中的文献带进下一轮写作。
