## Verdict

The take7 v3 video is acceptable as a long-form product demo master. It demonstrates the core workflow clearly: library preparation, full-library Q&A, traceable references, single-page Reader, in-paper references, literature basket, export, and library maintenance.

It is not yet a polished public-facing ad in the strictest sense. The main remaining gap is not missing functionality; it is pacing, subtitle placement, and a few credibility close-ups that should be sharpened.

## Remaining High-Priority Edits

1. Subtitle bar blocks UI on chat pages.

   The dark lower subtitle occasionally sits over the composer area and send button. It is readable, but it competes with the product UI. Move subtitles upward on chat pages or use a smaller lower-third that does not cover the input/composer.

2. Opening card is too long for an ad.

   The current 14-second opening is calm, but public ad rhythm should be tighter. Cut opening brand card to `6-8 s`, then enter the library dashboard earlier.

3. Add a stronger "real send" close-up.

   The end-to-end question is present, but a viewer should more obviously see: scope selection, typed question, send click, retrieval/generation state, answer appearing. A future take should give this sequence a clearer 20-30 second close-up.

4. Reader top evidence strip exposes raw Markdown/LaTeX syntax.

   The main paragraph is clean, but the current evidence strip shows text like math markup around `30 μm`. Do not zoom on that strip in the public edit, or improve rendering for the evidence preview.

5. Literature basket causality can be clearer.

   The basket ends with 6 items and works well, but the counter/feedback after each "入篮" action should be more visible. Add 1-2 tighter shots where a card is added and the basket count/state changes.

Under-shown:

- Conversion quality report or repair detail.
- Reference metadata enrichment details.

For a 15-minute product demo, this coverage is enough. For an investor/customer ad, add a 20-second quality-repair close-up and a 15-second citation-metadata close-up.
