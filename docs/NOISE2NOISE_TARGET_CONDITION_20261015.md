## 确定性复现与实际支撑

逐一重放 r25 两模式保存的原始 finalization 输入，而非重新生成后拿成功替代旧失败。
两份原始生成和重放答案均没有 target，适当统计量没有明确对应到输入条件下的训练目标分布。
r26 的 target 部分出现在 clean targets 等上下文，词组合同通过不证明该关系完整。
这些记录不是完整上游 LLM 请求抓取，不声称跨轮提示逐字相同。

第8页 Discussion 的直接对照只明确说其他方法需要完美显式污染模型，本方法仍需适当统计量
（mean、median）。它不能单独替代第2页的 L2 条件：输入条件下的目标分布可被具有相同条件
期望的分布替换，因此可向训练目标加入零均值噪声而不改变所学结果。
这不是所有损失函数都要求零均值，也不支持把条件移到训练输入、改成无条件均值或不同期望。
第2页冻结转换段落夹入实验介绍且长1401字符，关系后半部位于原1100字符预览之外；不伪装为
已经修复冻结转换的分栏，直接保留完整源块并精确选出其中真实存在的关系。

初始负例回归记录 `n2n-r27-red.log` 为2失败、8通过。来源完整，但原直接召回没有覆盖污染
模型问题；补全一看到 mean 就提前返回，忽略目标角色是否完整。
`n2n-r27-baseline-replay.json` 确认两模式旧失败。首个脚本因 Python 3.9 不支持 zip(strict=)
而未运行完成，日志单独保留，不计为产品失败。

## 修复与反例保护

- 按实际内容召回模型对照与目标条件两个段落，不依据论文标题推断关系。小于1800字符的
  直接源块完整进入同源上下文，普通检索块仍用原预览限制；两段保留各自页码及块ID。
- 新增小模块验证完整 L2、输入条件目标分布、相同期望、零均值训练目标关系；再次核验实际
  Markdown 块、路径和页码。仅完整直接依据可补全，mean 词本身不再使目标条件检查提前退出。
- 条件明确限定在 L2；反向关系、输入/目标互换、无条件期望、错误均值、L1、否定或残缺关系、
  错误来源、同名其他路径、空候选、源块变更和错误页码均不能授予该补全。
- 新直接条件确已提供时，移除旧生成中那一条“检索文本没有一般条件”的特定过时说明；
  不宣称补回完整证明或所有噪声/损失条件。
- 原计划已有第2页段落时，逐句定位原来直接跳过，最终仍借第8页卡片。现在唯一匹配的、
  经源块重新核实的次要段落也绑定当前引用句；不依赖相似词选择另一页。

`n2n-r27-occurrence-red.log` 保留该逐句缺口的先失败回归。
`n2n-r27-fixed-render-2.json` 是正确载入新计划后仍复用第8页的失败，
`n2n-r27-fixed-render-3.json` 中两份历史生成均分别指向实际第2页块
`blk_6a93682babb1_00030` / `p_00018`。
`n2n-r27-fixed-occurrence-audit.json` 另核对原PDF第2页三组条件短语。
更早的 render-1 投影漏换 answer_quality 计划及 refs.hits，保留为无效诊断尝试，不算产品验收。

r27 新鲜 API 又复现相反顺序：初始计划先选第2页时，第8页直接对照可能不进入计划。
因此两类直接段落现在按完整路径分别验证并独立保留，与初始主段落顺序无关；展示精确的
关系原句，保留同页完整段落用于校验。`n2n-r28-primary-selection-red.log` 先记录1失败、
15通过；修正后新增原始生成回放和卡片完整摘录保护，最终定向218通过。
不得用历史旧计划的重放取代这一新鲜生成发现。

进一步检查 r27 实际 finalization 输入发现：仅第2页作为 direct passage 留在生成上下文，
第8页已在此前的候选整理中丢失。仅新增计划槽无法恢复未传递的来源，第一次 r28 顺序重放
仍失败，保留 diagnostic 和 refreshed-replay 记录。回答候选确定前现在从已经限定范围的
实际候选来源重新读取这两个直接块，不从标题查找新论文，也不改变排序融合或支撑门槛。
`n2n-r28-r27-generation-refreshed-replay-2.json` 使用真实 r27 生成、明确补入新直接上下文，
两页均有自己的卡片；这不是同上下文重放或新的 LLM 生成。
新增槽同时携带核验过的同页完整段落用于 L2 校验，并以既有短关系 bundle 合同保留
条件期望和训练目标零均值两句，不把后一句摘录误称为完整条件。
