## 产品与框架边界

只服务于阅读库内文献、寻找和定位证据、比较与保存来源明确的摘录。
不增加写作、润色或投稿准备功能。保留 FastAPI + React + SQLite 架构，不做全栈重写。
BM25 保持默认和全库路径；本地语义检索仅在用户明确开启、选中文献/文献篮范围内使用。
外部网页与模型知识保持用户可选，并明确区分来源，不能伪装成库内证据。
