| 文件 | 应该由谁下载 | 使用方法 |

安装版和便携版都包含 `README-中文.md`、嵌入式 Python 运行时和预构建 React
前端。用户数据默认保存在 `%LOCALAPPDATA%\Pi_zaya`，覆盖安装、卸载安装版或
更换便携程序目录都不会删除个人文库。

### 本版重点

- 新用户首次成功路径：从文本模型设置、准备文献到获得第一条有引用的回答。
- API Key 供应商安全识别、主流服务商下拉框、模型发现和手动模型 ID 回退；
  网络或匹配失败采用短超时，不会一直卡在加载状态。
- PDF 转换任务持久化：应用退出后显示可恢复任务，由用户明确继续，复用已完成
  页面且不会在启动时自动消费模型额度。
- 多文档转换共享一个动态、工作保持型的 provider inflight 上限，同时保留
  源页顺序和结构质量门禁。
- 已移除未通过质量验证的页面调度、自适应预算和文本旁路实验。

## English download guide

This is a public beta that passed the complete source-quality and clean-profile
Windows release gates. Most users should download Setup; choose the portable ZIP
for no-install use or troubleshooting.

| File | Intended user | How to use it |
|---|---|---|
| `Pi_zaya-v0.1.0-beta.10-windows-x64-setup.exe` | Recommended for most Windows users | Verify it against `setup.exe.sha256`, run Setup, then launch Pi_zaya from the Start menu or optional desktop shortcut. It needs no administrator rights, system Python, or Node.js. |
| `Pi_zaya-v0.1.0-beta.10-windows-x64.zip` | Portable use or troubleshooting | Verify it against `.zip.sha256`, extract the entire archive to a normal folder, and double-click `Pi_zaya.exe`. Do not run it from the ZIP preview. |
| `*.sha256` | Anyone checking download integrity | A text checksum file, not an application. Compare it with `Get-FileHash <file> -Algorithm SHA256`. |
| `*.manifest.json` | Auditors and advanced users | Machine-readable version, commit, license, package type, and signing provenance. It is not an application. |
| GitHub-generated source archives | Developers building from source | These are not ready-to-run Windows packages. Use Setup or the portable ZIP for normal use. |

Both application packages include the Chinese guide, an embedded Python runtime,
and the prebuilt React frontend. User data defaults to `%LOCALAPPDATA%\Pi_zaya`
and survives in-place installation, uninstall, and portable-folder replacement.

### Highlights

- Guided first success from text-model setup to the first cited answer.
- Safe provider detection, provider/model dropdowns, manual model-ID fallback,
  and bounded discovery failures that cannot leave Settings loading forever.
- Durable, user-triggered conversion recovery with validated page-cache reuse and
  no automatic paid-model work on restart.
- A shared work-conserving provider-inflight limit for simultaneous documents,
  while keeping source-order submission and structural quality gates.
- Rejected page-scheduling, adaptive-budget, and text-local bypass experiments
  are absent from the runtime.
