## 中文下载说明

这是一个加入可追溯研究笔记与首次体验优化的 Windows 测试版。普通 Windows
用户推荐下载安装器；需要免安装、移动目录或故障排查时可以选择便携 ZIP。

| 文件 | 应该由谁下载 | 使用方法 |
|---|---|---|
| `Pi_zaya-v0.1.0-beta.13-windows-x64-setup.exe` | 推荐普通 Windows 用户 | 先用相邻的 `setup.exe.sha256` 核对文件，再运行安装向导。安装后从开始菜单或可选桌面快捷方式打开 Pi_zaya。无需管理员权限、系统 Python 或 Node.js。 |
| `Pi_zaya-v0.1.0-beta.13-windows-x64.zip` | 便携使用、移动目录或故障排查 | 先用相邻的 `.zip.sha256` 核对文件，将 ZIP 完整解压到普通文件夹，再双击 `Pi_zaya.exe`。 |
| `*.sha256` | 所有希望校验下载的用户 | 文本校验文件，不是应用程序。使用 PowerShell `Get-FileHash <文件> -Algorithm SHA256` 比较。 |
| `*.manifest.json` | 审计者和高级用户 | 机器可读的版本、提交、许可证、包类型和签名状态，不是应用程序。 |
| GitHub 自动生成的 Source code 压缩包 | 需要自己构建的开发者 | 不是可直接运行的 Windows 成品。普通用户请下载 Setup 或便携 ZIP。 |

安装版和便携版都包含 `README-中文.md`、嵌入式 Python 运行时和预构建 React
前端。用户数据默认保存在 `%LOCALAPPDATA%\Pi_zaya`，覆盖安装、卸载安装版或
更换便携程序目录都不会删除个人文库。

### 本版重点

- 新增独立的“研究笔记”工作区。笔记可以编辑、搜索、按项目或全局查看，并按
  文献、标签和时间筛选；常用笔记可以置顶，阶段性内容可以归档。
- 回答中的结论与引用可以整理进研究笔记。论文阅读器支持把选中的文字、表格、
  公式或图片加入新笔记或已有笔记，同时保留个人批注和精确原文位置。
- 同一处原文不会被重复追加；保存失败时，已选内容、目标笔记、标签和批注会继续
  保留，便于直接重试。
- 每条来源都保留页码、章节、锚点和摘录。打开来源可以回到对应回答或论文位置，
  表格保留原始 Markdown，公式保留原始 LaTeX。
- 多篇笔记可以组合为可编辑的写作提纲。单篇笔记可导出 Markdown 或 Word，Word
  文件名跟随笔记标题，中文标题也能正确保存。
- 首次使用时，文献管理页提供一份内置、自编的两页示例论文，可以直接体验转换、
  问答和引用定位。已有文献正在转换时，引导会显示转换进度入口。
- 严格转换质量门禁继续生效；证据矩阵及其依赖入口继续不向普通下载版本展示。
  文献库、PDF 转 Markdown、文库问答、引用定位、文内参考卡片、研究摘录篮和
  研究笔记继续正常提供。

### 校验和与签名边界

- 每个正式构建都必须同时提供 Setup、便携 ZIP、对应的 SHA-256 文件和两份
  manifest；相邻的校验文件是下载完整性校验依据。
- manifest 会记录准确的发布提交、`source_dirty=false`、MIT 许可证、嵌入式
  Python 运行时以及真实签名状态。
- 只有 manifest 记录 `signed: true` 且 Windows 验证受信任发布者时，构建才
  能称为已签名；否则该测试版会明确标记为未签名。

完整中文安装、API/模型、更新和卸载说明见软件包中的 `README-中文.md`，仓库版
见 [`packaging/windows/README-中文.md`](../../packaging/windows/README-中文.md)。

## English download guide

This Windows beta adds traceable research notes and a smoother first-use path.
Most Windows users should download Setup; choose the portable ZIP for no-install
use, removable folders, or troubleshooting.

| File | Intended user | How to use it |
|---|---|---|
| `Pi_zaya-v0.1.0-beta.13-windows-x64-setup.exe` | Recommended for most Windows users | Verify it against `setup.exe.sha256`, run Setup, then launch Pi_zaya from the Start menu or optional desktop shortcut. It needs no administrator rights, system Python, or Node.js. |
| `Pi_zaya-v0.1.0-beta.13-windows-x64.zip` | Portable use or troubleshooting | Verify it against `.zip.sha256`, extract the entire archive to a normal folder, and double-click `Pi_zaya.exe`. |
| `*.sha256` | Anyone checking download integrity | A text checksum file, not an application. Compare it with `Get-FileHash <file> -Algorithm SHA256`. |
| `*.manifest.json` | Auditors and advanced users | Machine-readable version, commit, license, package type, and signing provenance. It is not an application. |
| GitHub-generated source archives | Developers building from source | These are not ready-to-run Windows packages. Use Setup or the portable ZIP for normal use. |

Both application packages include the Chinese guide, an embedded Python
runtime, and the prebuilt React frontend. User data defaults to
`%LOCALAPPDATA%\Pi_zaya` and survives in-place installation, uninstall, and
portable-folder replacement.

### Highlights

- A dedicated Research Notes workspace supports editing, search, project or
  global scope, paper/tag/time filters, pinning, and archiving.
- Conclusions and citations from answers can be organized into a note. In the
  paper reader, selected text, tables, equations, and figures can be added to a
  new or existing note with a personal comment and an exact source locator.
- Duplicate source ranges are blocked before append. A failed save preserves
  the selected source, target note, tags, and comment for an immediate retry.
- Every source keeps its page, section, anchor, and excerpt. Source actions can
  reopen the answer or paper location; tables retain Markdown and equations
  retain LaTeX.
- Selected notes can be combined into an editable writing outline. Notes export
  to Markdown or real Word documents, with Unicode-safe title-based filenames.
- First use now offers a built-in, self-authored two-page sample paper for the
  conversion, Q&A, and citation-location path. When an imported paper is still
  converting, the guide links to conversion progress.
- The strict conversion-quality gate remains enabled. The evidence-matrix
  workspace and dependent entrances remain withheld from ordinary downloadable
  builds, while the library, PDF-to-Markdown conversion, grounded Q&A, citation
  locating, in-paper reference cards, literature basket, and Research Notes
  remain available.

### Integrity and signing boundary

- Every formal build must provide Setup, the portable ZIP, their adjacent
  SHA-256 files, and two manifests. The adjacent checksum files are the
  authoritative download-integrity records.
- The manifests record the exact release commit, `source_dirty=false`, the MIT
  license, embedded Python runtime, and observed signing state.
- A build is signed only when its manifest records `signed: true` and Windows
  validates the trusted publisher; otherwise this beta is explicitly unsigned.
