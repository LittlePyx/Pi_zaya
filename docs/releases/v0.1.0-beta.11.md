### 本版重点

- 证据矩阵及依赖它的研究简报、研究缺口和项目研究状态入口暂时不向普通用户
  展示。本次没有删除后端、已有数据或导出能力；待生成质量和交互门禁重做完成
  后再恢复。
- 文献库、PDF 转 Markdown、文库问答、引用定位、文内参考卡片、研究摘录篮、
  引用导出和本机快照继续正常提供。
- 改进跨页参考文献恢复，处理双栏 PDF 信号不完整和行尾断词导致的条目截断。
- 修复页面质量恢复时可能重复图、表、题注和已有正文的问题，只补入原页面真正
  缺失的来源正文。
- 新增双向发布门禁：普通构建必须确认高级研究入口不存在，内部构建仍必须通过
  完整证据工作流回归。

## English download guide

This is a quality-first beta patch. Most Windows users should download Setup;
choose the portable ZIP for no-install use, removable folders, or
troubleshooting.

| File | Intended user | How to use it |
|---|---|---|
| `Pi_zaya-v0.1.0-beta.11-windows-x64-setup.exe` | Recommended for most Windows users | Verify it against `setup.exe.sha256`, run Setup, then launch Pi_zaya from the Start menu or optional desktop shortcut. It needs no administrator rights, system Python, or Node.js. |
| `Pi_zaya-v0.1.0-beta.11-windows-x64.zip` | Portable use or troubleshooting | Verify it against `.zip.sha256`, extract the entire archive to a normal folder, and double-click `Pi_zaya.exe`. Do not run it from the ZIP preview. |
| `*.sha256` | Anyone checking download integrity | A text checksum file, not an application. Compare it with `Get-FileHash <file> -Algorithm SHA256`. |
| `*.manifest.json` | Auditors and advanced users | Machine-readable version, commit, license, package type, and signing provenance. It is not an application. |
| GitHub-generated source archives | Developers building from source | These are not ready-to-run Windows packages. Use Setup or the portable ZIP for normal use. |

Both application packages include the Chinese guide, an embedded Python
runtime, and the prebuilt React frontend. User data defaults to
`%LOCALAPPDATA%\Pi_zaya` and survives in-place installation, uninstall, and
portable-folder replacement.
