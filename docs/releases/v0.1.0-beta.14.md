### 本版变化

- 单篇和文献篮的可选本地语义检索使用用户选中的完整来源范围，并在该范围内取 top K。BM25 零命中时仍可补入范围内语义证据。文献篮的摘录限制在融合后再次生效。
- 默认与全库检索继续使用 BM25。本地语义组件仍需明确同意、验证和启用；组件清单未配置或运行时不可用时，保留 BM25。
- 本地便携候选包可附带独立验证的 multilingual-e5-small 组件压缩包；明确确认“安装并启用”后，从包内复制、校验、安装并建立索引，无需下载组件。压缩包约 286 MiB，安装约 514 MiB，另需索引与缓存空间。首次启动不会自动安装。回答生成仍需已配置的模型 API。
- 文献篮传递完整论文匹配信息及章节、块与锚点位置；通用“method”问题不再误限到 Methods 章节。明确请求章节时保留范围约束，对问题中点名的子章节提供软优先级。
- 回答证据修复增加对明确相反动作的中英文约束，例如存储/丢弃、训练/冻结、提高/降低。沿用数值、单位和来源身份检查；这些规则不等于完整语义蕴含验证。
- 首次使用区分已配置与已验证的模型连接。连接测试结果绑定当前配置并保留到重启后，不保存 API Key 或模型回复；修改配置后需要重新验证。
- 修复安装版直接打开阅读器、文献库和笔记地址时的页面入口；保留缺失 API 与静态资源的 404。
- 来源追问的上游引用贴到对应结论；修复成像公式路由、中英文公式关系对齐和并行采集机制摘录。快速与普通回答都应用来源引用绑定。
- “可用文献”按索引状态和实际分块文件计数。首次引导完成还需在回答证据对应的来源中成功定位，单纯打开论文不计为完成。
- 文献库、问答、引用定位、文献篮与研究笔记继续服务于阅读和来源明确的证据整理。内部证据矩阵及其依赖入口继续隐藏。

### 安装、数据与签名

用户数据默认位于 `%LOCALAPPDATA%\Pi_zaya`；升级或卸载软件不删除个人文库。
只有 manifest 记录 `signed: true` 且 Windows 验证受信任发布者时，才可称为已签名。
候选构建和公开发布分别记录，不将本地测试通过表述为远程 CI 或公开发行验收。

## English download guide

- `Pi_zaya-v0.1.0-beta.14-windows-x64-setup.exe`: per-user Windows x64 installer, with embedded Python and prebuilt React UI.
- `Pi_zaya-v0.1.0-beta.14-windows-x64.zip`: portable application; extract the entire archive and run `Pi_zaya.exe`.
- `*.sha256`: integrity checksums. `*.manifest.json`: source provenance and observed signing status.
- GitHub-generated source archives are developer source, not ready-to-run application packages.

This unpublished candidate fixes explicit selected-source semantic retrieval and post-fusion excerpt boundaries, adds conservative action-polarity constraints to answer repair, and makes first-use completion depend on verified model configuration, usable indexes and answer-linked evidence location. BM25 remains the default/full-library path. Optional semantic retrieval requires explicit consent and a verified component. Internal evidence workspaces remain hidden.

User data survives application upgrade/uninstall. Signing claims require both an accurate manifest and a trusted Windows signature. Publication is a separate step after candidate acceptance.
