## 修改边界

`kb/provenance_similarity.py` 仅复用默认 `SequenceMatcher(None, left, right).ratio()`
的精确浮点结果。有序键不能合并为无序键，因为该算法交换参数后可能给出不同结果。
缓存最多2,048项；任一字符串超过2,000字符就直接计算，不保留大输入。
使用标准线程安全 LRU；不缓存来源、页码、语义支撑、接受或拒绝决定。

`paper_guide_provenance.py` 的六处相似度计算复用此边界，原规范化、截断长度、
系数、阈值、候选顺序和异常处理保持原样，文件相对实际 main 缩小3行。
这一纯计算优化没有修改前端、依赖、原题集、原验收脚本、引用计划或渲染缓存协议；
后续新论文证据修复与必要的渲染缓存版本升级另外记录。
