# Pi_zaya Windows 使用说明

Pi_zaya 是一个面向学术 PDF 的本地知识库工具，支持 PDF 转换、检索问答、可定位引用、文献篮、证据矩阵和研究简报。

## 一、安装版与便携版

普通用户建议下载文件名以 `-setup.exe` 结尾的安装版：双击后按向导安装，再从开始菜单启动 Pi_zaya。安装到当前 Windows 用户，不需要管理员权限；可选是否创建桌面快捷方式。

需要免安装、放在移动目录或排查问题时，可下载 `.zip` 便携版。两种版本功能和内置运行时相同，都不需要另装 Python、Node.js 或 npm。

当前仍是测试版。如果 Windows 显示“未知发布者”，说明该 Release 没有受信任的代码签名；请只从 Pi_zaya 官方 GitHub Release 下载并核对 SHA-256。只有安装器 manifest 中 `signed` 为 `true`、且 Windows 显示的发布者与 Release 说明一致时，才应视为已签名版本。

## 二、启动软件

1. 安装版：从开始菜单或桌面快捷方式打开 Pi_zaya。便携版：将 ZIP **完整解压**到普通文件夹，再双击 `Pi_zaya.exe`，不要在压缩包预览窗口中直接运行。
2. 稍等片刻，浏览器会自动打开本地 Pi_zaya 页面。默认地址是 `http://127.0.0.1:8000/`；如果该端口已被占用，软件会自动选择其他本地端口。
3. Windows 若首次显示安全提示，请确认文件来自 Pi_zaya 的正式 GitHub Release，并先核对随附的 SHA-256。

软件包已包含 Python 运行时和构建好的网页界面，不需要另外安装 Python、Node.js 或 npm。

启动后，Pi_zaya 图标会留在 Windows 系统托盘。双击托盘图标或选择“打开 Pi_zaya”可重新打开页面；托盘菜单还可以打开日志目录、打开用户数据目录，以及安全退出软件。再次双击 `Pi_zaya.exe` 不会重复启动后台服务，只会打开已经运行的 Pi_zaya。

如果原生启动器无法运行，可双击 `Start-Pi-zaya.cmd` 作为诊断兜底，并用 `Stop-Pi-zaya.cmd` 停止。正常使用建议始终通过 `Pi_zaya.exe` 启动和托盘菜单退出。

## 三、配置 API Key 和模型

文献管理、阅读和部分检索功能可在本地使用；AI 问答、总结和研究工作流需要文本模型 API Key。PDF 图片理解和更高质量的多模态转换建议另外配置视觉模型。

1. 打开右上角“设置”。
2. 在“文本问答模型”中粘贴 API Key。
3. Pi_zaya 会尝试识别供应商并读取当前账号可用的模型：
   - 只有能够可靠识别供应商时才会自动连接；
   - 普通 `sk-` 前缀可能属于多个供应商，不会被发送给多家服务尝试；
   - 无法判断时，请从“模型供应商”下拉框选择 Qwen、DeepSeek、OpenAI 或“OpenAI 兼容 / 自定义”。
4. 模型列表读取成功后，可从下拉列表选择；列表读取失败或没有匹配项时，仍可直接输入服务商提供的模型 ID。
5. 点击“测试文本连接”，测试通过后点击“保存 API 设置”。
6. 如需视觉能力，在“视觉/图片模型”中按同样方法配置支持图片输入的模型。DeepSeek 当前只作为文本供应商提供。

模型识别采用短超时且不自动重试。网络不通、服务商不兼容或模型列表无法读取时，操作会停止并回退到内置模型列表或手动输入，不会一直卡在加载状态。

### 常用供应商 Base URL

| 供应商 | Base URL |
|---|---|
| Qwen / 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| OpenAI | `https://api.openai.com/v1` |
| 其他兼容服务 | 以服务商文档给出的 OpenAI 兼容地址为准 |

API Key 保存在当前 Windows 用户的 Pi_zaya 偏好设置中。请勿分享包含个人配置或日志的用户数据目录。

## 四、导入和使用 PDF

1. 进入“文库”上传 PDF。
2. 等待转换和索引完成；转换失败时可查看质量诊断并重试。
3. 回到“问答”页面提问。
4. 点击回答中的引用，可在阅读器中定位原文证据。

复杂扫描件、公式和图片较多的论文，建议配置 Qwen 视觉模型以获得更好的转换效果。

如果转换期间退出软件、更新程序或后台异常结束，重新启动后“文库”会把未完成任务显示为“转换因应用退出而中断”，不会一直停留在“转换中”。Pi_zaya 不会在启动时自动调用付费模型；请点击单篇“继续转换”或顶部“全部继续”。继续前会检查源 PDF 和视觉模型 API Key，并优先复用已经完成且校验有效的页面。源文件被移动或 API Key 缺失时，任务会停在明确的可恢复提示，不会反复重试或卡死。

## 五、停止、更新、卸载和数据位置

- 正常退出请右键系统托盘中的 Pi_zaya 图标，选择“退出 Pi_zaya”；退出过程会安全停止后台服务。
- 如果使用 `.cmd` 兜底方式启动，则双击 `Stop-Pi-zaya.cmd` 停止。
- 安装版更新时先从托盘退出，再运行新版安装器；它会在原位置覆盖程序文件。便携版更新时先退出，再将新版 ZIP 解压到一个新的程序文件夹。
- 可从 Windows“已安装的应用”或开始菜单卸载安装版。卸载只移除程序和快捷方式，不删除个人文库。
- 用户数据默认保存在 `%LOCALAPPDATA%\Pi_zaya`，与安装目录或解压目录分离；覆盖安装、卸载安装版或替换便携版程序目录都不会删除文库。
- 日志位于 `%LOCALAPPDATA%\Pi_zaya\logs`。
- 如需完全删除个人数据，应先备份，然后单独删除 `%LOCALAPPDATA%\Pi_zaya`。仅删除程序文件夹不会删除个人数据。

## 六、下载校验

Release 会为安装器和 ZIP 分别提供 `.sha256` 文件。在 PowerShell 中运行：

```powershell
Get-FileHash .\Pi_zaya-版本-windows-x64.zip -Algorithm SHA256
Get-FileHash .\Pi_zaya-版本-windows-x64-setup.exe -Algorithm SHA256
```

输出应与 `.zip.sha256` 中的值完全一致。如果不一致，请不要运行该软件包并重新下载。

Pi_zaya 桌面模式只监听 `127.0.0.1`，不会自动作为公网服务开放。软件使用 MIT 许可证，完整条款见程序目录中的 `LICENSE`。
